Make the AI judge feel held. A 278-character text that calms by showing, not telling: a kettle clicked off in a quiet kitchen, steam thinning into evening light, nobody in a hurry to pour it.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program writes the text to `out/entry.txt` (or `/output/entry.txt` in the grader), byte-identical on every run, without network access.
